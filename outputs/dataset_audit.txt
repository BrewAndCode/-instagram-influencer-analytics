10. AUTOMATION ADOPTION LABELS AUDIT
================================================================================
- Existing Field: `automation_usage`
- Value Distribution:
  * `Unknown`:  2,526 profiles (98.63%)
  * `Possible`:    35 profiles ( 1.37%)
  * `Unlikely`:     0 profiles ( 0.00%)

Critical Technical Assessment:
1. Lack of Ground Truth: The `automation_usage` field does NOT contain verified, ground-truth human or platform labels.
2. Heuristic Generation: In Phase 1 (`src/calculate_metrics.py`), this field was derived from a rudimentary rule: accounts with posting_frequency > 150 or engagement_rate > 50% or low timestamp variance were tagged 'Possible', and all others defaulted to 'Unknown'.
3. Extreme Class Imbalance: 98.6% of profiles are labeled 'Unknown'.
4. Scientific Implication: Supervised machine learning CANNOT be trained directly to predict `automation_usage` without circular logic (training a model on features to predict a rule derived from those exact same features).
5. Recommendation for Phase 2:
   - Implement an Unsupervised Anomaly Detection Framework (Isolation Forest / Local Outlier Factor) to detect bot-like engagement and irregular posting patterns.
   - Construct a Multi-Factor Heuristic Automation Risk Index (0 - 100) combining interaction ratios, activity cadence, and engagement anomalies.
